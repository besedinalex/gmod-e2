# Garry's Mod Expression 2

Just a bunch of personal Expression 2 stuff

## Installation

Copy `cap/` to `C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\data\expression2\cap`

## In-game limits

Adjust with game console:
```
wire_expression2_quotatick 100000
wire_egp_max_objects 1000
```
*Note*: It probably doesn't need that much, but at least it's a reference for the commands
